# 🎮 DETEKTIF DUNIA MAYA — LKPD Informatika Kelas 8

Aplikasi web LKPD interaktif (berbasis game sederhana) untuk mata pelajaran **Informatika Kelas VIII / Fase D** pada materi **Jejak Digital, Privasi, Keamanan, dan Anti-Phishing** (*Digital Footprint, Privacy, Security, and Anti-Phishing*).

- **Modul:** `MATERI_K8P14_GANJIL`
- **Satuan Pendidikan:** SMP Negeri 19 Kota Bekasi
- **Penyusun:** TIM MGMP Informatika SMP Negeri 19 Kota Bekasi
- **Tahun Ajaran:** 2026 / 2027
- **Model Pembelajaran:** Problem Based Learning (PBL)
- **Elemen:** Literasi Digital (mencakup Dampak Sosial Informatika)

Game terdiri dari **5 level** yang memetakan indikator ketercapaian (I-1 s.d. I-5):
1. 🔍 **Jejak Digital** (Digital Footprint)
2. 🚨 **Oversharing Alert**
3. 🔐 **Password Builder** (+ 2FA)
4. 🎣 **Phishing Detector**
5. 🆘 **Darurat! Akun Diretas** (Account Emergency)

Dilengkapi badge (Master/Expert/Junior/Trainee Detective), checklist keamanan digital, papan peringkat lokal, refleksi, dan sertifikat cetak — semuanya **dwibahasa Indonesia–Inggris**.
